# Stronger engine for Hard and the coach

**Asked:** build a better Go engine for the app.

**Changed:**
- New file `search.js`: tree search (Monte Carlo tree search with RAVE) over fast random games that follow simple Go rules of thumb (capture stones in atari, rescue your own, avoid filling your own eyes or self-atari). Local only, no network, no neural network.
- `engine.js`: `chooseMove` hands the Hard and Expert levels to `search.js`. Easy and Medium are unchanged. `suggest` was shortened to one line (same behaviour) to keep engine.js under 500 lines (now 497).
- `index.html` and `sw.js` load `search.js`. Two new tests in `test.js`.

**Decided:** only Hard (computer) and the coach's hints (which run at Hard or Expert) use the new engine, so beginners on Easy/Medium see no change. Thinking times are unchanged.

**Results (Node, same 1 second per move for both):** new Hard beat old Hard 20 of 20 games on 9×9 (by about 10–15 points) and 4 of 4 on 13×13. Speed: about 5,400 random games a second on 9×9, about 1,300 on 19×19.

**Left:** analysis (alternative moves, game review) still uses the old method; could switch to the new search later. Not tried in a browser.

**Try it:** Vercel preview → Play → Computer level Hard. Ask for a hint to see the coach's new suggestions.
