# Version stamp, fairer score bar, New clears chat, enlarge chat

**Asked (from a phone screenshot):** 1) show the update date under the title; 2) why the bar showed 33:67 on an empty board; 3) New should clear the chat too; 4) a way to enlarge the chat and shrink it back.

**Changed:**
1. `index.html`/`style.css`/`update.js`: "Updated 23 Nov 2026, 12:42 pm" under the title (hidden in short landscape). The old long-press-the-title toast in `main.js` was removed, as the stamp replaces it.
2. The bar is Black's chance of winning. It came from plain random games, which ignore the value of having the move, so on an empty board White's 6.5 komi made White look far ahead (old method gives about 36:64 on an empty 9x9). `coaching.js` now uses a short read with the tree search in `search.js` (0.4 s on 9x9): empty 9x9 shows about 48:52. The bar no longer uses the Analyse win rates (those still use the old method).
3. `main.js`: starting a game from the New dialog clears the chat first (`clearChat` exposed from `chat.js`). The first-launch welcome is not affected.
4. `chat.js`/`style.css`: enlarge/shrink button (arrows icon) at the top right of the chat; enlarged, the chat covers the screen; tap again (or Esc) to return.

**Checked:** `node test.js` passes. In headless Chromium at Pixel 7 size: stamp shows, bar 48:52 on an empty board, enlarge and shrink work, New leaves only the new-game message, no page errors. Not tried on a real phone.

**Left:** Analyse percentages and hints still use the older method.
