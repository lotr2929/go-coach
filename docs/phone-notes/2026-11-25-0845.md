# The chat as folded exchanges, with sessions and a history

**Asked (Boon):** organise the chat as a history listed by questions; separate sessions with a date-time stamp; a new session clears the board and the chat; pulling down from the top shows the history; each exchange folds to the question, tap to open, stays open until tapped again. Boon chose: a new session starts on New **and** on reopening after a long break (an hour); the newest answer stays open.

**Earlier the same session (already in PR #18):** no tint behind the coach's messages; typed words plain grey; welcome ends "Type Tour to start a tour of the app." (Boon asked whether the tour starts by itself on first install: it does not.)

**Changed:**
- New file `chatlog.js` (in index.html and sw.js, before chat.js): keeps the current session (`gocoach.chat`, now `{start, last, log}`; an older saved list of messages is taken over) and the history (`gocoach.chatPast`, last 30 sessions). Draws the chat as exchanges (`.ex`, question button `.q`, answers `.ans`), folds earlier ones, handles pull-down (touch, mouse wheel at the top, or tapping the hint).
- `chat.js`: no longer stores or draws messages; `say` and questions go through `G.chatRecord`; the lessons menu goes through `G.chatShow`; quick replies and menu/welcome choices head their exchange (the green-box removal earlier still holds: questions are plain headings now).
- `main.js`: New starts a new chat session; after more than an hour away a new game starts instead of restoring the old one (`G.awayStart`).
- `telemetry.js`: follows the nested layout (questions and messages inside exchanges; the history is not logged again).
- Wording in `chat.md`: history-hint, notes, welcome-head.

**Checked:** 70 tests pass; in a headless phone-size browser: the welcome and stamp show; asking twice folds the first; tapping opens and closes; New clears the board and chat and offers the history; pulling down shows the earlier session with its stamp and folded questions; a two-hour gap on reopening starts a new game with the welcome and archives the old chat. Not tried on a real phone (the touch pull was simulated with the mouse wheel).

**Left:** Clear still empties the current session without keeping it.

**Follow-up (Boon):** the one-hour rule is dropped. Only New starts a new session; leaving or reopening the app returns you to where you were (on a phone the system may reload a background app, so time away cannot be told apart from reopening). `G.awayStart` removed.

**Follow-up (Boon):** question headings marked with a plain • instead of triangles. History keeps 100 sessions (free tier; Boon: a paid tier keeps them all, not built yet); if localStorage is full, the oldest sessions are dropped until it fits.

**Follow-up (Boon):** in the history, sessions from earlier days (device's local date) fold into a day heading (e.g. "Monday 24 November 2026"); inside, each session is a time heading ("8:26 am") that opens its folded questions. Today's earlier sessions are shown as before. `drawPast` and `fold` in chatlog.js.

**Follow-up (Boon):** today's earlier sessions also fold to their date and time; only the current session shows its questions directly. Days, sessions and questions are all shown as clickable text (italics, thin dotted underline, `.link`), the same as the coach's choices.
