# 2026-11-28 10:20 — old welcome kept showing "What is Go?"

**Asked:** after "Why Play Go?" went live, Boon's phone still showed the old wording.

**Found:** the page file itself was live. But a welcome already saved in the chat is only replaced by today's welcome when it
starts with "Hello, I am your Go coach". Since the beta line was put first, saved welcomes start with "Go Coach is in beta",
so they were never refreshed and kept their old wording (and lost their buttons).

**Changed:** chatlog.js `freshen` now also recognises the greeting after a first paragraph.
