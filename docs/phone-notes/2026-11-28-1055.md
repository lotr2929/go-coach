# 2026-11-28 10:55 — one text size for the chat and the reading pages

**Asked:** the text of "Why Play Go?" looked much larger than the chat on Boon's phone. Boon wants one text size across the app,
so changing one changes all, and fonts of the same size should look the same height.

**Changed (style.css):**
- `--text` (in :root, .95rem) is the reading size of both the chat messages (.msg) and the pages (.pageBody). Page headings,
  lists, cards and references are in em, so they follow it. Settings > Text size still scales the whole app.
- `font-size-adjust: 0.52` on every element (with !important, because the many `font:` shorthands would reset it): every font
  is drawn with the same letter height at the same size, so the serif pages match the sans chat. 0.52 is about the system
  sans fonts' own x-height, so the rest of the app barely changes.
- An earlier try on this branch (page text scaling with the board's width) was replaced by this, at Boon's request.

**Checked:** in a phone-sized and a laptop-sized Chrome: page text and chat text are both 15.2px, with the same letter height.
Not tried on a real phone.

**Try it:** open Why Play Go? and compare its text with the chat.
