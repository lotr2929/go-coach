# Move tree under the game buttons (like SmartGo)

**Asked:** Boon sent a SmartGo screenshot and asked for "the feature at the bottom": the move tree with branches.

**Changed:**
- New file `movetree.js` (in index.html and sw.js): a strip under the game buttons in the side panel. Every move of your own game is a dot (black or white), numbered every 10 moves; a square marks the start. When you undo and play something else, the new line branches off below and the old one stays. The current move has a green ring; moves off the current line are faint.
- Tap any dot to go to the position after that move (`jumpTo` in play.js, like Undo/Redo: shared moves are kept, the rest are taken back and the chosen line replayed). If it is then the computer's turn, it plays (and may choose a different move, which makes a new branch). Going back along the same line leaves Redo able to return.
- The tree is saved with the game (`Play.tree` in the saved game) and starts fresh with New. Older saved games get a tree from their moves.
- Wording: `play.md` (tree-move, tree-pass, tree-start), `screen.md` (move-tree.aria, move-tree.tip).

**Decided:** the strip sits in the side panel, not under the board, so the board keeps its size. It shows only in your own game (hidden in lessons, Teach me, exploring and Kifu, which hide the game buttons). It is a record, not help, so it shows in silent Play mode too. It only works while the game is in play (greyed while counting or after the game ends).

**Left:** reviewing a finished game through the tree; ±10-move buttons; the same tree for famous games (Kifu).

**Checked:** 70 tests pass; tried in a headless browser (desktop and iPhone size): branches drew correctly, tapping a dot jumped back, the tree came back after a reload, no errors. Not tried on a real phone.
