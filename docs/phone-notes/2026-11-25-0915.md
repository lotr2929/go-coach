# Earlier coach's messages fold to their first line

**Asked (Boon):** condense the coach's responses so only the current one shows in full, with earlier ones revealed as needed. Offered three options; Boon chose "each message folds to its first line".

**Changed:** `chatlog.js` folds every coach's message except the newest (`clipOlder`, class `clip`), in the current session and in the history; tapping a message opens or folds it (taps on buttons inside, such as the welcome's choices, still work). The lessons menu is never folded. `style.css`: a folded message shows one line with "…", in italics with a thin dotted underline like the other clickable text.

**Checked:** 70 tests pass; in a headless phone-size browser, three earlier messages folded to one line each, the newest stayed open, and tapping one opened it. Not tried on a real phone.
