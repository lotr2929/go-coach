# 2026-11-28 10:30 — an update no longer closes a reading page

**Asked:** Boon tapped "Why Play Go?" and "A Short History of Go" just after opening the app; the chat said the page was open
but the board showed. The page had opened, then the automatic update (two versions went live that morning) reloaded the app.

**Changed:** update.js counts an open reading page as busy, like lessons and famous games: it shows the "new version is ready"
notice instead of reloading. It also checks again just before the reload, so a page opened in that moment stays open.

**Try it:** open a page right after a new version goes live; it stays open and a notice says an update is ready.
