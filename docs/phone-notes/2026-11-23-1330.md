# Easier, reliable updates for the installed app

**Asked:** an easier way to refresh the installed PWA on the phone, and to be sure it refreshes.

**Why it was unreliable:** the service worker already loads files from the network first, so a true restart gets the new version. But phones often only resume the app from memory, so the old page stays on screen.

**Changed:**
- New file `update.js`: whenever the app is opened or brought back to the front it checks for a new version; if one arrives it reloads itself (the game is saved after every move and resumes). During a lesson, guided teaching, exploring or a famous game it shows a notice instead of reloading.
- Settings: new "Check for updates" button (always reloads the newest files; says if offline) and a line showing this version's date.
- `index.html`, `sw.js` load `update.js`.

**Checked:** `node test.js` passes. In headless Chromium (served locally): the service worker controls the page, the button and version date show in Settings, and tapping the button reloads the page. Not tried on a real phone.

**Try it:** after merging, do the old close-and-reopen once more to get this version. From then on, switching back to the app updates it automatically, or use Settings → Check for updates.
