# The tour starts by itself on first install

**Asked (Boon):** make the tour start automatically on first install (Boon thought it already did; it did not: a first visit only showed the welcome).

**Changed:** `chatlog.js` exports `G.firstVisit` (true when nothing was saved yet); `main.js` starts the tour once, 0.8 s after start-up, on a first visit. Later visits do not start it; it is still available from "How to use the app" or by typing Tour.

**Checked:** 70 tests pass; in a headless phone-size browser with empty storage the tour started by itself, and after closing it and reloading it did not start again. Not tried on a real phone.
